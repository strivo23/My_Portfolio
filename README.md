## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: Modern Vanilla CSS Design Tokens (Editorial warm off-white `#F8F8F5` & deep charcoal `#111214`)
- **Icons**: Lucide React + Custom SVG Icons
- **Typography**: Google Fonts (Plus Jakarta Sans + JetBrains Mono)
- **Features**: Responsive layout, Light/Dark mode with `localStorage` persistence, interactive architectural previews, and accessible candidate resume modal.

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/strivo23/My_Portfolio.git
   cd My_Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Build production bundle:**
   ```bash
   npm run build
   ```
